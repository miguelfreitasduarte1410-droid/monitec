# Monitec EDU — Site reformulado

Site estático com layout redesenhado, adaptado para celular e computador. Os arquivos estão prontos para GitHub Pages e Vercel (sem compilação, dependências ou chaves de API).

## Páginas

- `index.html` — início
- `empresa.html` — apresentação da Monitec
- `produto.html` — imagens do produto e seleção entre as versões azul/branca; clique na imagem para ampliar
- `perguntas.html` — FAQ pesquisável e área para copiar uma pergunta e enviá-la pelo Instagram
- Instagram — o botão abre o perfil `https://www.instagram.com/monitec.edu92/` em outra guia

## Publicação

1. Extraia o ZIP.
2. Envie **todos** os arquivos da pasta para a raiz do repositório GitHub, incluindo a pasta `assets`.
3. No Vercel, importe o repositório e use o framework **Other** (site estático), sem comando de build.
4. Ou acesse pelo GitHub Pages habilitando a publicação da branch principal e pasta `/ (root)`.

Para testar localmente, abra `index.html` em um navegador. As demais páginas são arquivos independentes, não uma única página de rolagem.

## Observações

- As imagens da logo e dos fones foram fornecidas pelo usuário e apenas otimizadas para WebP.
- Não foram inventadas especificações técnicas, preços, disponibilidade, ou promessas de recursos do produto.
- A área de perguntas oferece respostas prontas e permite copiar uma pergunta para envio manual; **não é um chat com IA** nem envia mensagens automaticamente.
- O perfil do Instagram foi informado pelo usuário; o conteúdo da conta não foi verificado neste projeto.
